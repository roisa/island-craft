# Letter recordings (optional)

Put recorded pronunciations here and the game will use them instead of the
device's text-to-speech:

- `0.mp3` … `27.mp3` — the letter name (0 = Alif, 1 = Ba, … 27 = Ya)
- `0-a.mp3`, `0-i.mp3`, `0-u.mp3` … — the letter with fathah / kasrah / dhammah

Recordings by a qari/teacher are strongly recommended before release.
